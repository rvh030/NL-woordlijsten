# NL-woordlijsten
Een verzameling van Nederlandse woordlijsten

- '[basiswoorden.txt](/basiswoorden.txt)' zijn door de TaalUnie goedgekeurde woorden. Is een lijst van 13.439 woorden. Het oorspronkelijke bestand is [hier te vinden](https://github.com/OpenTaal/opentaal-wordlist?tab=readme-ov-file).
- '[NL_voornamen.txt](/NL_voornamen.txt)' is een overzicht van alle Nederlandse voornamen, peildatum onbekend. Is een lijst van 660.346 namen.
- '[top_wachtwoorden.txt](/top_wachtwoorden.txt)' is een samenvoeging van de top 20 meest gebruikte wachtwoorden door particulieren en organisaties. Is een lijst van 28 wachtwoorden.
